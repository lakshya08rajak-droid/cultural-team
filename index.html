SUPABASE DATABASE SETUP GUIDE

Connect your persistent cloud database in 2 minutes:

Step 1: Create a free project at supabase.com.
Step 2: Open the SQL Editor in your Supabase dashboard and run the script located at supabase/schema.sql. This creates the tables, indexes, row-level security (RLS), and upvoting stored procedure.
Step 3: In Supabase Project Settings > API, copy your:
  • Project URL
  • anon public API key
Step 4: Paste them into js/config.js or set environment variables in your Vercel project deployment:
  • VITE_SUPABASE_URL or window.__SUPABASE_ENV__.url
  • VITE_SUPABASE_ANON_KEY or window.__SUPABASE_ENV__.anonKey
